# План 04: Аналитика и учет посещений сайта

## Статус: ⏳ В очереди (Active)
**Ветка:** `feat/compliance-cookies-spam-warning`  
**Цель:** Организовать анализ посещаемости сайта в полном соответствии с законодательством РФ (Яндекс.Метрика + автономный микро-трекер).

---

## Задачи

- [ ] **4.1. Интеграция Яндекс.Метрики (`index.html`, `script.js`)**
  - Подключить официальный асинхронный код счётчика Яндекс.Метрики (серверы в РФ, поддержка Вебвизора, карты скролла и кликов).
  - Настроить переменную ID счётчика (по умолчанию заглушка или рабочий ID при наличии, с подробной инструкцией в коде).
  - В `script.js` при успешной отправке заявки вызывать цель Метрики:
    `ym(COUNTER_ID, 'reachGoal', 'lead_submit');`

- [ ] **4.2. Автономный микро-трекер визитов (`tracker.php`)**
  - Создать легковесный PHP-скрипт для фиксации визитов на сервере Timeweb:
    - Дата и время (МСК).
    - URL страницы и реферер (откуда пришёл посетитель).
    - Тип устройства / User-Agent.
    - **Анонимизированный IP-адрес** (маскирование последней части IP согласно 152-ФЗ и правилам приватности).
  - Подключение без торможения загрузки страниц (фоновый асинхронный `sendBeacon` или `fetch`).

- [ ] **4.3. Тестирование и верификация**
  - Проверка отправки события цели при сабмите формы.
  - Проверка записи логов локального трекера.

- [ ] **4.4. Фиксация в `CHANGELOG.md` и Git коммит**
