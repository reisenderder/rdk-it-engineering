# Work Plans (Планы работ RDK IT Engineering)

Данная директория предназначена для пошагового ведения и трекинга задач проекта, исключая перемешивание процессов.

## Структура папок

* `workplans/active/` — планы текущих задач, находящихся в процессе реализации или подготовки к выполнению.
* `workplans/completed/` — успешно выполненные, протестированные и принятые планы работ (архив).

## Правила работы

1. Каждая крупная задача или логический блок оформляется отдельным markdown-файлом с нумерацией и чек-листом.
2. Задачи реализуются строго последовательно («по чуть-чуть, пункт за пунктом»), без смешивания правок.
3. По завершении каждого пункта:
   - Обновляется статус в файле плана (`[x]`).
   - Фиксируются подробные записи в `CHANGELOG.md`.
   - Делается атомарный коммит в ветку задачи.
4. После полного завершения и проверки плана он перемещается из `workplans/active/` в `workplans/completed/`.
