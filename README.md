# RDK IT Engineering — корпоративный сайт

Одностраничный презентационный сайт IT-компании RDK IT Engineering.

## Позиционирование

- сайты и веб-платформы;
- мобильные приложения;
- Telegram-боты и mini apps;
- автоматизация бизнес-процессов;
- интеграции, данные и AI-инструменты;
- аудит, стабилизация и сопровождение систем.

Сайт выдержан в мягкой инженерно-премиальной эстетике: единая типографика, близкие по тону каменно-шалфейные поверхности и тёплый металлический акцент. «Код Наследия» представлен отдельным блоком RDK Lab как авторский проект компании, а не как её основной визуальный образ.

Услуги сгруппированы в три направления: цифровые продукты, автоматизация, инженерия и надёжность. В каждом пакете указан типовой состав и стартовый бюджет.

## Структура

- `index.html` — разметка, стили и JavaScript;
- `assets/tower-neon.jpg` и `assets/tower-neon-sm.jpg` — изображения блока RDK Lab;
- `assets/tower-warm.jpg` и `assets/tower-warm-sm.jpg` — резервная пара кадров.

## Локальный запуск

Можно открыть `index.html` напрямую или запустить локальный сервер:

```bash
python -m http.server 8777
```

После этого открыть <http://127.0.0.1:8777>.

## Перед публикацией

1. Подтвердить ссылку на Instagram `@rdk_it_engineering`.
2. При необходимости добавить email, Telegram и юридические данные.
